# Wireframe Specification: `/login` (B2B Authentication & Portal Login)

**UI Route:** `/login`  
**Injected Functional Modules:** `MOD-UI` (Authentication Guard & Session Management).  

---

## 1. Cognitive Analysis & Recommended UX Pattern

- **Diagnosis:** Users entering the platform want to authenticate quickly and securely. Unclear validation errors or rate limiting failures cause frustration.
- **Primary UX Pattern:** `Split-Screen Layout (50% Form / 50% Brand Showcase)`. On Desktop, 50% left side for the clean login form on a white/dark container, and 50% right side for an illustrative branding graphic showcasing real-time reconciliation metrics. On Mobile, 100% full-width form.

---

## 2. UI Inventory (Atomic Design)

### A. Atoms
- `AuthInput` (Email / Password fields. *Variants: Default, Focus, Error with red border*).
- `PrimaryButton` (Full-width button: "Sign In to Portal". *Variants: Default, Hover, Disabled, Loading with Spinner*).
- `Heading` (H1: "Welcome Back", Subtitle: "Sign in to access your reconciliation workspace").
- `Checkbox` ("Remember this device for 30 days").
- `Link` ("Forgot Password?").
- `Icon` (Mail, Lock, Eye, EyeOff, AlertCircle).

### B. Moléculas
- `AuthFormField` (Label + `AuthInput` + Error Helper Text).
- `PasswordToggleField` (`AuthInput` with eye icon toggle).
- `AuthHeaderBlock` (SmartReconcile Logo + H1 Heading + Subtitle).

### C. Organisms
- `LoginFormBlock` (Logo + Email Field + Password Field + Remember Me Checkbox + Submit Button + Help Link).
- `BrandShowcaseBlock` (Right 50% split pane rendering live animation preview of sub-millisecond Java matching).

---

## 3. Spatial Heuristics & Accessibility (Layout Rules)

1. **Thumb Zone Target (Mobile):**
   - Submit button must span 100% container width with a minimum height of `48px`.
2. **Keyboard Navigation & Auto-Focus:**
   - Auto-focus on Email field upon page load. Pressing `Enter` in the password field submits the form.
3. **High Contrast Error Messages:**
   - Error messages must render in high-contrast red (`#DC2626`) with an accompanying `AlertCircle` icon for color-blind accessibility.

---

## 4. The Designer Checklist (Figma Artboard Tasks)

### ✅ Base Screens (Happy Path)
- `[ ]` **Desktop (1440px):** Split-screen 50/50 layout.
- `[ ]` **Mobile (390px):** Single-column full-width container.

### ✅ Transitory States (Async Mutations)
- `[ ]` **Loading State:** Submit button disabled showing a rotating `Spinner` icon with text "Authenticating...".

### ✅ Excepciones y Muros (Unhappy Paths)
- `[ ]` **Invalid Credentials Error:** Input border turns red with message "Invalid email or password."
- `[ ]` **Rate Limit Warning:** Toast banner stating "Too many failed login attempts. Please wait 15 minutes."
