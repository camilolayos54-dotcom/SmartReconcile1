# Wireframe Specification: `/dashboard` (Reconciliation Overview Dashboard)

**UI Route:** `/dashboard` (Private Authenticated Route)  
**Injected Functional Modules:** `MOD-DET` (Matching Core), `MOD-AGT` (AI Status), `MOD-UI` (KPI Metrics & Multi-Currency Selector).  

---

## 1. Cognitive Analysis & Recommended UX Pattern

- **Diagnosis:** Finance managers and analysts need an immediate high-level summary of daily reconciliation status, match rate percentages, system throughput, and unaddressed discrepancy queues, with multi-currency view support.
- **Primary UX Pattern:** `Executive Command Dashboard (4-Card Metric Grid + Split Activity Stream)`. Top bar incorporates a Base Currency Selector (`USD`, `EUR`, `COP`, `MXN`); top 4-card metric grid for instant status, followed by a 2-column layout: left column for live ingestion stream feed, right column for urgent discrepancy alerts.

---

## 2. UI Inventory (Atomic Design)

### A. Atoms
- `Heading` (H1 Page Title: "Reconciliation Dashboard", H2/H3 Card Titles).
- `Text` (Metric Values, Timestamp Labels, Subtitles).
- `Select` (Global Base Currency Selector: `USD ($)`, `EUR (€)`, `COP ($)`, `MXN ($)`).
- `Badge` (Status Badges: `MATCHED` - Green `#12B76A`, `DISCREPANCY` - Amber `#F79009`, `CORRUPTED` - Red `#F04438`).
- `Icon` (CheckCircle, AlertTriangle, TrendingUp, RefreshCw, Cpu, Activity, Globe).
- `Spinner` (Inline loading indicator for live stream updates).
- `Button` (Primary: "Run New Batch", Secondary: "View All Discrepancies").

### B. Moléculas
- `MetricCard` (Combines `Icon` + `Heading` + `Text` value in selected Currency + Percentage Delta Badge).
- `StatusBadgePill` (Combines `Badge` + `Text` label).
- `LiveStreamItem` (Combines `Timestamp` + `StatusBadgePill` + Transaction RefID + Amount).

### C. Organisms
- `HeaderNavbar` (Global Top Bar with Tenant Switcher, Base Currency Selector, WebSocket Online Indicator `#12B76A`, and User Avatar).
- `TopMetricsGrid` (4 Grid Columns containing: `Total Ingested Volume`, `% Matched Rate (99.2%)`, `Pending Discrepancies (12)`, `Financial Leakage Recovered ($4,850 USD / €4,450 EUR)`).
- `LiveActivityFeedBlock` (Real-time scrolling table showing Java `MOD-DET` match stream results).
- `UrgentAlertsBlock` (Actionable card list highlighting items requiring `MOD-AGT` or manual sign-off).

---

## 3. Spatial Heuristics & Accessibility (Layout Rules)

1. **Fitts's Law & Touch Targets:**
   - Primary action buttons ("Run New Batch") must maintain a minimum height of `44px` on desktop and `48px` on mobile displays.
2. **Accessibility (a11y) & Color Contrast:**
   - Status badge text must maintain WCAG AA contrast ratio ≥ 4.5:1 against dark/light background fills (e.g., `#027A48` dark green text on `#ECFDF3` light green background).
3. **WebSocket Reconnection & Fallback:**
   - If WebSocket connection drops, UI renders an amber warning banner ("Reconnecting to Live Feed... (Attempt 2/5)") and falls back gracefully to 15-second REST polling.

## 4. The Designer Checklist (Figma Artboard Tasks)

### ✅ Base Screens (Happy Path)
- `[ ]` **Desktop (1440px):** Full 4-card metric grid + Currency Selector + 2-column live stream and discrepancy list.
- `[ ]` **Mobile (390px):** Single-column stacked layout with sticky top navbar.

### ✅ Transitory States (Async Operations)
- `[ ]` **Loading State:** Metric cards render Tailwind `animate-pulse` Skeleton boxes while fetching REST APIs.
- `[ ]` **WebSocket Reconnecting State:** Amber header banner showing connection backoff timer.

### ✅ Excepciones y Muros (Unhappy Paths)
- `[ ]` **WebSocket Disconnected Fallback:** Yellow alert banner at top of dashboard indicating live stream fallback to 15-second polling.
- `[ ]` **Empty State:** Clean empty card state when no transactions have been ingested today.
