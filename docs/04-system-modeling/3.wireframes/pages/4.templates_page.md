# Wireframe Specification: `/templates` (Bank Schema Template Studio)

**UI Route:** `/templates`  
**Injected Functional Modules:** `MOD-ING-TPL` (Bank Template Manager), `MOD-UI`.  

---

## 1. Cognitive Analysis & Recommended UX Pattern

- **Diagnosis:** System administrators need to configure, visual-map, and test reusable bank statement column schemas so future bank files parse deterministically at zero AI cost.
- **Primary UX Pattern:** `Studio Workbench (Active Template Gallery + Drag & Drop Column Mapper Canvas)`. Top section displays registered bank schemas; main area provides a visual column mapper canvas with dry-run test capability.

---

## 2. UI Inventory (Atomic Design)

### A. Atoms
- `Heading` (H1 Title: "Bank Schema Template Studio").
- `Button` (Primary: "Save & Publish Template", Secondary: "Test Dry Run", Ghost: "Duplicate Schema").
- `Input` (Text field for Template Name, Regex Header Signature).
- `Select` (Native/Custom dropdown for Date Format selection: `YYYY-MM-DD`, `DD/MM/YYYY`).
- `Badge` (`PRODUCTION` - Green, `DRAFT` - Amber, `TESTED_OK` - Blue).
- `Icon` (LayoutGrid, Sliders, Play, Plus, Trash2, Check, RefreshCw).

### B. Moléculas
- `BankTemplateCard` (Bank Logo Icon + Bank Name + File Format Badge + Last Used Date).
- `ColumnMappingRow` (Sample Raw File Column + Arrow Icon + Target Field Select Dropdown).
- `FormatConfigGroup` (Decimal Separator Select + Date Layout Select + Encoding Select).

### C. Organisms
- `TemplateGalleryBlock` (Grid list of active and draft bank statement parsing schemas).
- `VisualColumnMapperStudio` (Interactive mapping canvas associating raw file columns with system database fields).
- `DryRunTestConsole` (Execution console displaying sample file extraction results and line item match rates).

---

## 3. Spatial Heuristics & Accessibility (Layout Rules)

1. **Mapping Row Alignment:**
   - Each column mapping row must maintain strict horizontal alignment with clear visual directional arrows (`Sample Column [1] ----> [ Target Field Dropdown ]`).
2. **Keyboard Navigation & Dropdowns:**
   - All target field select dropdowns must support keyboard search auto-complete (`Tab` focus + type to filter).
3. **Dry-Run Output Visibility:**
   - Test execution console sits fixed at the bottom with dark theme styling (`bg-gray-900 text-green-400 font-mono`) for terminal-like clarity.

---

## 4. The Designer Checklist (Figma Artboard Tasks)

### ✅ Base Screens (Happy Path)
- `[ ]` **Desktop (1440px):** Active template cards gallery + visual column mapper workbench + dry-run console.
- `[ ]` **Mobile (390px):** Template list view with modal drawer for mapping edits.

### ✅ Transitory States (Async Operations)
- `[ ]` **Testing State:** Dry-run button showing loading spinner with text "Parsing Sample Rows...".

### ✅ Excepciones y Muros (Unhappy Paths)
- `[ ]` **Mapping Parse Error:** Console window displaying red error message: "Row 3 Parse Error: Could not parse date string '2026/31/08' using format YYYY-MM-DD."
- `[ ]` **Duplicate Signature Error:** Warning toast stating "Regex signature collides with existing template 'Chase_CSV_v2'."
