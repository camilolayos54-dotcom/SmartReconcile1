# Wireframe Specification: `/onboarding` (Initial Bank & SFTP Setup Wizard)

**UI Route:** `/onboarding`  
**Injected Functional Modules:** `MOD-ING-TPL` (Bank Schema Manager), `MOD-UI` (Organization Setup).  

---

## 1. Cognitive Analysis & Recommended UX Pattern

- **Diagnosis:** Newly registered organizations need a step-by-step wizard to set up their base operating currency, connect their primary acquiring bank accounts, and configure SFTP/S3 statement sync settings without feeling overwhelmed.
- **Primary UX Pattern:** `Progressive 3-Step Wizard (Multi-Step Stepper + Form Workbench)`. Step 1: Base Currency & Organization Details; Step 2: Primary Acquiring Bank Selection & SFTP Credentials; Step 3: Initial Bank Template Verification (`MOD-ING-TPL`).

---

## 2. UI Inventory (Atomic Design)

### A. Atoms
- `Heading` (H1: "Set Up Your Organization Workspace").
- `Button` (Primary: "Continue to Step 2", Secondary: "Back", Success: "Complete Setup & Launch Dashboard").
- `Input` (Organization Name, SFTP Host Address, SFTP Port, S3 Bucket Path).
- `Select` (Base Display Currency: `USD ($)`, `EUR (€)`, `COP ($)`, `MXN ($)`).
- `Badge` (`STEP 1 OF 3` - Blue, `CONNECTED` - Green).
- `Icon` (Building, CreditCard, Server, ShieldCheck, ArrowRight, CheckCircle).

### B. Moléculas
- `WizardStepHeader` (Step Number Badge + Step Title + Progress Line Bar).
- `BankCardSelector` (Selectable bank card with Bank Logo + Supported Formats MT940/CSV/PDF).
- `SFTPCredentialForm` (Host Input + Port Input + Key Upload + "Test Connection" Button).

### C. Organisms
- `OnboardingWizardBlock` (3-Step Stepper Header + Dynamic Form Body + Bottom Action Bar).

---

## 3. Spatial Heuristics & Accessibility (Layout Rules)

1. **Stepper Visual Continuity:**
   - Step indicator bar sits fixed at the top of the wizard container with active step highlighted in emerald green (`#10B981`).
2. **SFTP Test Feedback:**
   - "Test Connection" button displays a live inline spinner and green success badge ("SFTP Handshake Verified in 120ms") before allowing advance to Step 3.

---

## 4. The Designer Checklist (Figma Artboard Tasks)

### ✅ Base Screens (Happy Path)
- `[ ]` **Desktop (1440px):** 3-Step Wizard with Step 1 (Currency/Org), Step 2 (SFTP/Bank Selection), Step 3 (Template Setup).
- `[ ]` **Mobile (390px):** Single-column wizard with step navigation controls at bottom.

### ✅ Transitory States (Async Operations)
- `[ ]` **Connection Testing State:** SFTP credentials button displaying spinner with text "Testing SFTP Handshake...".

### ✅ Excepciones y Muros (Unhappy Paths)
- `[ ]` **SFTP Connection Failed:** Red alert card stating "SFTP Connection Failed: Connection timed out on port 22. Please verify host IP and SSH keys."
