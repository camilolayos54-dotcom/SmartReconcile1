# Wireframe Specification: `/landing` (Public B2B SaaS Landing Page)

**UI Route:** `/landing` (or `/` for unauthenticated visitors)  
**Injected Functional Modules:** Commercial Marketing Engine, Interactive ROI Calculator, Product Demo Preview.  

---

## 1. Cognitive Analysis & Recommended UX Pattern

- **Diagnosis:** CFOs, VPs of Finance Ops, and Technical Leads need an immediate understanding of how SmartReconcile solves manual reconciliation overhead and financial leakage without risking LLM hallucinations in production.
- **Primary UX Pattern:** `High-Impact B2B SaaS Landing Page (Hero + Feature Cards + Interactive ROI Calculator + Pricing Grid + CTA Bar)`. High visual contrast using Tailwind dark mode aesthetics, vibrant gradients, and live interactive widgets.

---

## 2. UI Inventory (Atomic Design)

### A. Atoms
- `Heading` (H1 Hero Title: "Autonomous Financial Reconciliation Powered by Java & Agentic AI").
- `Button` (Primary: "Book an Enterprise Demo", Secondary: "Start 14-Day Free Trial", Ghost: "Sign In").
- `Badge` (`SOC-2 TYPE II CERTIFIED` - Green, `10,000+ TPS` - Blue, `90% FEWER MANUAL HOURS` - Amber).
- `Icon` (Zap, ShieldCheck, Cpu, ArrowRight, DollarSign, Clock, CheckCircle).
- `Input` (Interactive ROI Calculator Sliders: Monthly Transaction Volume, Current Finance Headcount).

### B. Moléculas
- `HeroCTAContainer` (Primary Button + Secondary Button + "No Credit Card Required" Micro-Text).
- `FeatureCard` (Icon + Title + Description Text + Interactive Code/Graph Snippet).
- `ROICalculatorWidget` (Volume Slider + Hours Saved Display + Annual Financial Leakage Recovered Text).
- `PricingTierCard` (Tier Name + Price Tag + Feature List Checkmarks + "Choose Plan" Button).

### C. Organisms
- `PublicHeaderNavbar` (Logo + Nav Links: Features, Architecture, ROI, Pricing + "Sign In" Button).
- `HeroSectionBlock` (H1 Title + Subtitle + Hero Image/Interactive Product Mockup + CTA Container).
- `ArchitectureHighlightsBlock` (Comparison Card: Legacy Manual VLOOKUP vs. SmartReconcile Dual-Core Engine).
- `ROICalculatorBlock` (Interactive calculator letting prospect CFOs estimate dollar savings in real time).
- `PricingSectionBlock` (3-Tier Pricing Grid: Starter $2,000/mo, Enterprise $5,000/mo, Custom Scale).
- `PublicFooter` (Product Links, Security & Compliance Badges, Legal Terms, Copyright).

---

## 3. Spatial Heuristics & Accessibility (Layout Rules)

1. **Hero Fitts's Law Dominance:**
   - The primary CTA button ("Book an Enterprise Demo") must be prominent with high contrast gradient fill (`bg-gradient-to-r from-emerald-500 to-teal-600 text-white min-h-[52px] px-8 text-lg font-bold rounded-xl shadow-lg`).
2. **Interactive ROI Slider Accessibility:**
   - Volume sliders must support keyboard arrow adjustments and aria-labels for screen reader accessibility.
3. **Contrast & Aesthetics:**
   - Dark background theme (`#0F172A` / `#020617`) paired with crisp emerald and teal accents (`#10B981` / `#14B8A6`).
