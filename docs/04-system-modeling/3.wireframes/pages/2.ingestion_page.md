# Wireframe Specification: `/ingestion` (Bank Statement Ingestion Studio)

**UI Route:** `/ingestion`  
**Injected Functional Modules:** `MOD-ING` (Statement Ingestion & Vision Parsing Engine), `MOD-UI`.  

---

## 1. Cognitive Analysis & Recommended UX Pattern

- **Diagnosis:** Users need to upload batch statement files (PDF, CSV, MT940), see whether a cached template (`MOD-ING-TPL`) was matched, and preview Vision-LLM extracted table rows without confusion.
- **Primary UX Pattern:** `Split-Pane Workspace (Drag & Drop Zone + Data Extraction Preview Table)`. Top section for drag-and-drop file upload, lower section for interactive statement processing status and extracted data validation table.

---

## 2. UI Inventory (Atomic Design)

### A. Atoms
- `Heading` (H1 Title: "Bank Statement Ingestion Studio").
- `Button` (Primary: "Upload Statement", Secondary: "Cancel Upload", Icon Button: "Download JSON").
- `Input` (Hidden File Input: `type="file"`, Accept: `.pdf,.csv,.txt,.mt940`).
- `Badge` (`TEMPLATE_MATCHED` - Green, `VLM_PARSED` - Blue, `MANUAL_REQUIRED` - Amber).
- `Icon` (UploadCloud, FileText, CheckCircle2, AlertCircle, Eye, Settings).
- `Progress bar` (Linear progress indicator showing file upload percentage).
- `Spinner` (Processing spinner during VLM parsing calls).

### B. Moléculas
- `UploadDropzone` (Dashed border container + UploadCloud Icon + "Drag PDF/CSV here" Heading + "Browse Files" Button).
- `FileProcessingCard` (File Icon + Filename Text + Size + Progress Bar + Cancel Button).
- `ExtractionAccuracyPill` (Badge + Confidence Percentage Score Text "99.4% Precision").

### C. Organisms
- `IngestionHeaderBlock` (Title + Bank Selector Dropdown + Quick Settings Button).
- `UploadZoneBlock` (Interactive Drag & Drop Container supporting multi-file queuing).
- `ParsedDataPreviewTable` (Interactive data grid displaying extracted rows: `Date`, `Ref ID`, `Description`, `Debit`, `Credit`, `Balance`).

---

## 3. Spatial Heuristics & Accessibility (Layout Rules)

1. **Dropzone Touch & Target Area:**
   - Dropzone box must have a minimum height of `180px` with dotted border (`border-2 border-dashed border-gray-300 dark:border-gray-700`).
2. **Keyboard Accessibility:**
   - Dropzone area must be focusable via `Tab` key and trigger file selection modal on `Space` or `Enter`.
3. **Error Feedback Contrast:**
   - Corrupted file warning banners must use high-contrast red fill (`#FEF2F2`) with dark red text (`#991B1B`).

---

## 4. The Designer Checklist (Figma Artboard Tasks)

### ✅ Base Screens (Happy Path)
- `[ ]` **Desktop (1440px):** Drag & Drop dropzone + active batch parsing queue + extracted data preview grid.
- `[ ]` **Mobile (390px):** Compact "Tap to Upload" button + scrollable data summary card.

### ✅ Transitory States (Async Operations)
- `[ ]` **Uploading State:** Active file card rendering `Progress bar` filling up to 100%.
- `[ ]` **VLM Parsing State:** Table skeleton rendering animated pulsing rows with text "Vision-LLM Extracting Table Rows...".

### ✅ Excepciones y Muros (Unhappy Paths)
- `[ ]` **Unsupported File Format Error:** Red alert toast stating "Invalid file type. Only PDF, CSV, MT940, and BAI2 formats are supported."
- `[ ]` **Corrupted Balance Error:** Alert card showing math error: "Page 1 balance check failed: Net delta of +$5.20 detected."
