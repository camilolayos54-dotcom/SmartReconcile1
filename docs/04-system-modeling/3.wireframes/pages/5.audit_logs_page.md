# Wireframe Specification: `/settings/audit-logs` (System Admin & Audit Logs)

**UI Route:** `/settings/audit-logs`  
**Injected Functional Modules:** `MOD-DET` (Audit Ledger), `MOD-UI` (SOC-2 Compliance Viewer & Signed PDF Audit Exporter).  

---

## 1. Cognitive Analysis & Recommended UX Pattern

- **Diagnosis:** Compliance officers and system administrators need an immutable, tamper-evident log of all system actions, matching decisions, AI proposals, and human approvals with downloadable cryptographically signed PDF reports for SOC-1 and SOC-2 Type II audits.
- **Primary UX Pattern:** `High-Density Data Grid (Filter Toolbar + Multi-Column Paginated Table + Detail Drawer)`. Top filter bar for filtering by date range, operator, event type, and status; main area for the high-density log table with "Export Signed PDF Audit Report" action.

---

## 2. UI Inventory (Atomic Design)

### A. Atoms
- `Heading` (H1 Title: "System Audit & Compliance Logs").
- `Button` (Primary: "Export Signed PDF Audit Report", Secondary: "Reset Filters", Ghost: "Copy Hash").
- `Input` (Search Input: "Search by Transaction RefID or Event ID").
- `Select` (Event Type Filter: `ALL`, `MATCH_EXECUTED`, `AI_PROPOSAL`, `OPERATOR_APPROVED`, `REJECTED`).
- `Badge` (`APPROVED` - Green, `REJECTED` - Red, `SYSTEM_AUTO` - Blue).
- `Icon` (ShieldCheck, Search, Filter, Download, Lock, ExternalLink, Calendar, FileText).

### B. Moléculas
- `AuditFilterToolbar` (Search Input + Date Range Picker + Event Type Select + Export Signed PDF Button).
- `AuditLogRow` (Timestamp + Event ID + Event Type Badge + Operator ID + RefID + Cryptographic Hash).
- `AuditHashBadge` (Lock Icon + Monospace Short Hash `0x7f8a...` + Copy Button).

### C. Organisms
- `AuditLogTableBlock` (Paginated, sortable high-density data grid displaying immutable system events).
- `AuditDetailDrawer` (Slide-over drawer displaying full JSON payload metadata, IPC headers, and operator signatures).

---

## 3. Spatial Heuristics & Accessibility (Layout Rules)

1. **High Data Density:**
   - Table rows use compact padding (`py-2.5 px-4 text-xs font-mono`) to maximize visible records per screen (at least 20 rows visible on 1080p).
2. **Cryptographic Hash Copy Target:**
   - Monospace hash badges must provide a visual click feedback toast ("Hash Copied to Clipboard").
3. **Keyboard Table Navigation:**
   - Table rows support `Up/Down` arrow key navigation and `Enter` key to open the detail drawer.

## 4. The Designer Checklist (Figma Artboard Tasks)

### ✅ Base Screens (Happy Path)
- `[ ]` **Desktop (1440px):** Filter bar + 20-row audit table + slide-over detail metadata drawer + PDF Export Toolbar button.

### ✅ Transitory States (Async Operations)
- `[ ]` **Exporting Report State:** Export button showing loading spinner with text "Generating SOC-2 Signed PDF Report...".

### ✅ Excepciones y Muros (Unhappy Paths)
- `[ ]` **No Log Results:** Clean empty table state stating "No audit logs found matching the selected date range and filters."
- `[ ]` **Tamper Detection Warning:** High-priority red banner if cryptographic hash verification fails: "Tamper Warning: Audit hash mismatch detected on Row #4,102."
