# Definition of Done (DoD) & Definition of Ready (DoR) (Deliverable 9)

**Project:** SmartReconcile  
**Document ID:** D9-DEFINITION-OF-DONE  
**Phase:** 2 — Project Kickoff  

---

## 1. Definition of Ready (DoR)

A user story or feature task is ready for sprint planning only if:
1. Feature acceptance criteria are clearly specified and approved by Product Lead.
2. API / gRPC Protobuf schema contracts are defined and committed.
3. Dependencies and external mock data are identified.

## 2. Definition of Done (DoD)

A user story or engineering task is marked DONE only when:
1. Code is fully implemented according to coding standards.
2. Unit and integration tests pass with **≥85% code coverage**.
3. Peer code review approval obtained from at least 1 senior developer.
4. CI/CD pipeline builds successfully without lint or security warnings.
5. Technical documentation updated in `/docs`.
