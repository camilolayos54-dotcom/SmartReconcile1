## 1. Project Mission & Name

- **Project Name:** SmartReconcile
- **Repository Identifier:** `smartreconcile`
- **Mission Statement:** To eliminate financial ledger corruption, operational friction, and month-end accounting close delays by combining a high-throughput Java 21 deterministic matching engine with an explainable Python Agentic AI root-cause coprocessor and an interactive React dashboard.

## 2. Core Engineering Principles

1. **Deterministic Financial Integrity First:** The Java core must maintain strict 100% mathematical accuracy. AI agents only provide explainable proposals—never unverified ledger mutations.
2. **Zero-Hallucination Guardrails:** AI discrepancy proposals must be validated against double-entry accounting rules prior to operator review.
3. **Decoupled Asynchronous IPC:** Java matching core and Python AI coprocessor communicate via asynchronous gRPC / Kafka payloads to prevent AI latency from blocking core ledger batch runs.
4. **Auditability by Design:** Every match, mismatch, and AI-suggested adjustment must carry an immutable audit trail for SOC-1 / SOC-2 compliance.
