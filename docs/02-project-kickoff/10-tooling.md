## 1. Tooling Infrastructure Matrix

- **Version Control:** Git & GitHub.
- **Build Tools:** Maven / Gradle (Java), Poetry / Pip (Python), Vite / npm (React).
- **CI/CD Orchestration:** GitHub Actions.
- **Static Analysis & Linting:** SonarQube, SpotBugs (Java), Black/Flake8 (Python), ESLint/Prettier (React).
- **Containerization & Local Dev:** Docker Desktop, Docker Compose, Minikube.
- **API Documentation & Testing:** Swagger / OpenAPI 3.0, Postman, BloomRPC (for gRPC).
